# ZooRiff test builds

Public download point for ZooRiff Android test builds. Source lives in a private repository.

**Latest Android APK:** https://github.com/hannuverkasalo-finland/zooriff-releases/releases/latest/download/ZooRiff.apk

Install: open the link on an Android phone, download, tap the file, allow installs from this source when asked.
Test builds are debug-signed and not from Google Play.
